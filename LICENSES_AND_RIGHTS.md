# Лицензии и права на материалы

Этот файл — контрольный список для проекта `video-farm`, а не юридическое заключение. Перед коммерческой публикацией проверьте актуальные условия источника и сохраните подтверждение лицензии для каждого стороннего компонента/медиафайла.

## Озвучка и модели TTS

Единый статус выбора TTS ведётся в `docs/01_SRS.md` и `docs/DECISION_TTS.md`.

### Piper

- Программа Piper распространяется отдельно от этого проекта; актуальный upstream и лицензия движка: <https://github.com/OHF-Voice/piper1-gpl>.
- В проекте по умолчанию используется голос `ru_RU-dmitri-medium` из <https://huggingface.co/rhasspy/piper-voices/tree/main/ru/ru_RU/dmitri/medium>.
- Карточка конкретного голоса указывает язык ru_RU и лицензию датасета CC0: <https://huggingface.co/rhasspy/piper-voices/blob/main/ru/ru_RU/dmitri/medium/MODEL_CARD>. В репозитории голосов видна метка MIT, но это не заменяет проверку прав на саму модель, датасет и условия Piper на момент использования.
- Карточки Dmitri и Denis также сообщают о fine-tuning from U.S. English Lessac; коммерческие права на эти downstream-веса и их аудио не считаются подтверждёнными. Подробности: `docs/06_piper_licensing_audit.md`.
- Другие голоса автоматически не подменяются: многие модели имеют ограничения, включая NC. Если меняете голос, изучите именно его `MODEL_CARD` и сохраните копию лицензии.

### Kokoro-ru v2 (кандидат, пока не интегрирован)

- Оригинальная Kokoro-82M обозначена Apache-2.0, но русские веса `zaakirio/kokoro-ru` обозначены OpenRAIL; код русского порта заявлен Apache-2.0.
- Лицензия Dialogs разрешает коммерческое использование при соблюдении поведенческих ограничений. Её раздел 3 требует передавать лицензию и use-restrictions получателям распространяемых производных материалов; соответствие этому условию для выходов, включённых в публичный видеоролик, ещё не закрыто. См. `docs/07_kokoro_ru_licensing_review.md`.

## Стоковые видео и изображения

- Список файлов, URL страницы, автор и источник записываются в `assets_manifest.json`.
- Pexels API и правила: <https://www.pexels.com/api/documentation/> и <https://www.pexels.com/license/>.
- Pixabay API и правила: <https://pixabay.com/api/docs/> и <https://pixabay.com/service/license-summary/>.
- Наличие API-результата не гарантирует пригодность конкретного файла для любой коммерческой цели. Проверьте ограничения на узнаваемых людей, бренды/логотипы, товары, объекты собственности и редакционное использование.
- В итоговом описании указывается источник только тех файлов, которые действительно присутствуют на диске. Если стоки не скачаны, шаблонный текст об атрибуции надо исправить до публикации; не оставляйте ложное утверждение об использованном B-roll.

## YouTube Data API

- Анализ использует официальный YouTube Data API v3 и не скачивает чужие видео. Документация и квоты: <https://developers.google.com/youtube/v3/docs> и <https://developers.google.com/youtube/v3/getting-started>.
- Не копируйте сценарии, кадры, музыку или миниатюры найденных каналов. Используйте только агрегированные метрики для исследования интереса к темам.

## Python-зависимости

Основные зависимости устанавливаются из `pyproject.toml`. Перед распространением модифицированной сборки проверьте лицензии конкретных установленных версий. Пакеты Piper и внешние модели не вшиты в архив проекта, а устанавливаются/скачиваются пользователем отдельно.

- `num2words>=0.5.14,<0.6` используется для ограниченной нормализации русских числительных, дат и величин. Метаданные PyPI указывают LGPL; зафиксируй конкретную установленную версию и сохрани её текст лицензии перед распространением приложения: <https://pypi.org/project/num2words/>. В текущем тестовом контейнере эта зависимость не установлена; unit-тесты использовали mock. Это не означает, что лицензия на распространение уже закрыта.
- Нормализатор консервативный: распознаёт только поддержанные конструкции. Неразобранные цифровые токены выводятся в TTS-манифесте для ручной проверки; это не универсальная система морфологического разбора русского языка.

## Перед публикацией

1. Проверить `fact_checks` и первоисточники.
2. Проверить лицензию каждого стороннего файла по URL из `assets_manifest.json`.
3. Прослушать озвучку и исправить ударения, омографы и произношение брендов.
4. Удалить либо исправить атрибуцию для источников, которые фактически не использовались.
5. Проверить действующие правила площадки, маркировку и применимые требования законодательства РФ.
