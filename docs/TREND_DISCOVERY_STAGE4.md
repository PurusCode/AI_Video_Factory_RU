# Discovery Stage 4 — локальная редакторская HTML-панель

## Назначение

Stage 4 формирует автономную HTML-страницу из полного массива `unique_candidates` сохранённого `discovery.json` schema 2.0. Страница работает локально в браузере, не запускает сервер, не использует CDN и не делает сетевых запросов. Все 1 894 (или иное фактическое число) уникальных записей доступны через поиск, фильтры, сортировку и пагинацию.

## Команда

```powershell
.\.venv\Scripts\python.exe -m video_farm.cli discover-editor
```

Параметры:

- `--input output/discovery/discovery.json` — исходный Discovery v2 JSON;
- `--out output/discovery` — каталог, куда записывается `editor.html`.

Результат: `output\discovery\editor.html`. Откройте файл двойным щелчком в браузере.

## Функции

- поиск по названию и каналу;
- фильтры по контексту рынка, поисковому направлению, периоду, длительности, исходному `category_id`, ручной языковой метке, ручной метке формата, редакторской теме и статусу;
- сортировка только по исходным полям `view_count` и `published_at`;
- пагинация 25/50/100/200;
- статусы: не отмечено, в отборе, отложено, исключено;
- ручные заметки, отметка просмотра, язык и формат;
- создание редакторской темы из отмеченных видео и добавление видео к существующей теме;
- импорт/экспорт редакторских решений в `editorial.json`.

## Структура редакторского экспорта

Экспорт содержит идентификаторы видео и решения редактора, но не дублирует названия, статистику, даты публикации или другие сырые поля YouTube API. Экспорт привязан к времени формирования исходного отчёта; импорт в другую версию Discovery отклоняется.

## Ограничения и обработка данных

- Интерфейс не классифицирует содержание, не определяет язык автоматически, не рассчитывает трендовые показатели, отношения или рейтинги.
- `RU` и `Global` — контексты поисковых запросов, не установленный язык видео.
- Поле формата — ручная отметка редактора; длительность не преобразуется в утверждение о типе YouTube Shorts.
- Просмотры, лайки и комментарии отображаются как исходные API-поля.
- Страница содержит копию полей YouTube API и наследует срок `refresh_or_delete_by_utc` исходного отчёта. Создание страницы после истечения срока блокируется.
- `discover-cleanup` удаляет `editor.html` и расположенный в каталоге отчётов `editorial.json` вместе с `discovery.json`, `discovery.md`, `topics.json` и `topics.md` после истечения срока.
- Если пользователь экспортирует `editorial.json` в другое место, его также следует удалить или обновить к сроку, указанному в отчёте. Не коммитьте `editor.html` и редакторский экспорт в публичный репозиторий: HTML содержит исходные поля YouTube API.
