# Discovery v2 — широкое обнаружение популярных видео

## Что изменилось

- Поиск перестал быть привязанным к нейросетям / ИИ.
- Добавлены 10 заранее настроенных широких поисковых направлений.
- Российская выдача (`regionCode=RU`, `relevanceLanguage=ru`) отделена от международной выдачи (без `regionCode`, с `relevanceLanguage=en` как приоритетом).
- Для каждого направления выполняется поиск за 24 часа и 7 дней.
- Добавлена обработка `nextPageToken`: по умолчанию запрашивается до двух страниц на поисковый набор.
- Добавлено ограничение `search.list` до 90 вызовов на запуск. При достижении ограничения отчет отмечает неполноту.
- Детали уникальных видео загружаются пакетно через `videos.list` (до 50 ID за вызов), а повторы между направлениями/периодами объединяются по `video_id` с сохранением `found_in`.
- Дополнительно читается официальный `mostPopular` чарт для RU и US. Он является дополнительным сигналом, а не полным обзором всех тематик.
- Отчет показывает длительность, дату публикации, просмотры, лайки, комментарии и канал. Отдельная автоклассификация Shorts/long-form не включена.

## Поисковые направления

1. Новости и события
2. Технологии и наука
3. Экономика, бизнес и финансы
4. Спорт
5. Игры и гейминг
6. Кино, музыка и развлечения
7. Автомобили и транспорт
8. Путешествия, еда и образ жизни
9. Образование и история
10. Дом, ремонт и DIY

Эти подписи обозначают заранее заданные поисковые запросы. Они не являются результатом автоматического анализа и присвоения тегов содержимому найденных видео.

## Команда

```powershell
.\.venv\Scripts\python.exe -m video_farm.cli discover
```

Параметры:

- `--max-results 25` — размер страницы, 1–50;
- `--max-pages 2` — максимум страниц для каждого направления/рынка/периода, 1–3;
- `--search-call-budget 90` — ограничение `search.list` на запуск, 1–100;
- `--query "..."` — вместо десяти широких направлений запустить один пользовательский запрос для двух рынков и двух периодов;
- `--region RU` и `--language ru` — параметры российской выдачи.

Стандартная конфигурация: 10 направлений × 2 рынка × 2 временных окна = 40 первых страниц; до 80 `search.list` вызовов при наличии второй страницы во всех наборах. Лимит 90 оставляет резерв для прочих операций. Дополнительно выполняются два запроса `videos.list` для чартов RU/US и пакетные запросы для статистики уникальных видео. Квоты `videos.list` относятся к отдельному стандартному бюджету Data API.

## Чего система не обещает

- `order=viewCount` ранжирует найденные видео по полному числу просмотров, а не по приросту за час/сутки.
- Сочетание `viewCount` с `publishedAfter` может возвращать неполную выборку — это предупреждение документации YouTube. Пагинация забирает доступные страницы до лимита, но не превращает результат в полный рейтинг всего YouTube.
- Международная выдача без `regionCode` и с `relevanceLanguage=en` — не полный набор всех стран/языков и не строго англоязычный фильтр.
- `mostPopular` не является all-topic чартом: YouTube описывает его как охватывающий, прежде всего, trending music, movies and gaming.
- По умолчанию не вычисляются view velocity, custom trend score, engagement ratio, viral ratio, комментарийный sentiment или автоматические topic tags.

## Политика YouTube API

Стандартные Developer Policies запрещают использовать API Data для создания новых или производных данных/метрик, если для этого нет применимого разрешения. Отдельная политика дополнительных производных метрик включает, среди прочего, Content Categorization and Tagging и Custom Channel Scores and Ratios; она доступна только audited developers с аналитическим use case, которые явно подали заявку и получили согласование. До отдельного подтверждения разрешения эти функции в проект не включаются.

Сохранённые данные, подпадающие под Non-Authorized Data, должны быть обновлены или удалены в пределах 30 календарных дней. В отчёте остаётся `refresh_or_delete_by_utc`; `discover-cleanup` удаляет просроченные `discovery.json` и `discovery.md` в указанном каталоге.

## Формат отчёта

- `search_sets`: результаты каждого отдельного поискового запроса;
- `unique_candidates`: объединение по `video_id` без вычисления рейтинга; `found_in` сохраняет происхождение каждого совпадения;
- `most_popular_charts`: отдельные выборки chart для RU и US;
- `quota_usage`: фактическое число вызовов API.

Markdown показывает до 10 роликов на каждый поисковый набор. Полный полученный результат и raw-счётчики сохраняются в JSON.
