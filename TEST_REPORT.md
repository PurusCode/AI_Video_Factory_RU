# Отчёт тестирования video-farm

Дата исходного отчёта: 2026-10-16
Актуализация: 2026-10-26 (TTS normalizer v0.2.2; gender-aware forms and punctuation fix)

## Результаты

- Синтаксическая проверка: `python -m compileall -q src tests` — успешно.
- Автоматические тесты после патча v0.2.2: `PYTHONPATH=src python -m pytest -q -rs` — **33 passed, 1 skipped** (real `num2words` integration test skipped because package is unavailable in the network-isolated container).
- Добавлена проверка передачи `PYTHONUTF8=1` и `PYTHONIOENCODING=utf-8` процессу Piper на Windows.
- Добавлены диагностические предупреждения для подозрительно длинной озвучки относительно количества слов.

## Ограничения

Автоматические тесты используют имитацию запуска Piper и не могут оценить слышимое качество русской речи. В пользовательском Windows-запуске четыре WAV были созданы, однако пользователь сообщил, что речь звучит как бессвязные буквы и числа. Этот прогон не считается успешным. Добавлен хотфикс возможного неправильного декодирования UTF-8 в дочернем процессе Windows; требуется повторно синтезировать контрольный сценарий и прослушать результат.

## Воспроизводимая команда на Windows

```powershell
.\.venv\Scripts\python.exe -m video_farm.cli tts --script data/piper_control_script.json --out output/piper-control-fixed --speed 1.0
```

Папка `output/piper-control-fixed` выбрана специально, чтобы сохранить предыдущие WAV для сравнения.

## Дополнение 25.10.2026 — ручной тест произносимого текста

Пользователь сообщил, что числа стали звучать правильно, когда были заранее преобразованы в слова с согласованными окончаниями. Это ручной/изоляционный тест на входном тексте, а не новый автоматический тест и не доказательство внедрённого нормализатора. Добавлены unit-тесты ограниченного числового нормализатора, поэтому общее число тестов выросло до 30. В текущем контейнере `num2words` не установлен (сетевой доступ к PyPI недоступен); числовые unit-тесты используют детерминированный тестовый двойник. Реальное поведение `num2words`, нормализованный текст и повторное аудио на Windows должны быть подтверждены отдельно. Это не меняет ручные оценки качества: Kokoro Dima 3,5/5, Piper Dmitri 2,5/5; ни один голос не принят.

## Автоматическая нормализация текста TTS v0.2.1 — 25.10.2026

- Вызовы русской локали стандартизированы на коротких кодах `case` `n/g/d/a/i/p`. Исходный код `num2words 0.5.14` также принимает английские aliases, поэтому прежний код не считаем доказанной причиной runtime-сбоя. Mock-тесты теперь используют единый канонический формат.
- Моки тестов приведены к публичному API пакета. Добавлен интеграционный тест, который автоматически проверяет реальный `num2words`, когда он установлен; в окружении без доступа к PyPI он пропускается.
- `PYTHONPATH=src python -m compileall -q src tests tools` и `PYTHONPATH=src python -m pytest -q`: результат будет указан после повторного прогона. Этот контейнер не имеет доступа к PyPI, поэтому настоящий пакет здесь не удалось установить; проверка его реального результата остаётся обязательной на Windows.
