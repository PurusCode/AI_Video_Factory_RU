# Discovery Stage 3 — редакторские подборки из Discovery v2

## Назначение

Stage 3 принимает готовый `discovery.json` версии 2.0 и формирует два дополнительных отчёта: `topics.json` и `topics.md`. На этом этапе это **не автоматическое семантическое выделение трендов**. Модуль строит редакторские подборки из уже полученных записей, не обращаясь к YouTube API.

## Что делает

1. Проверяет структуру и версию исходного отчёта.
2. Использует `found_in` как точное происхождение записи: рынок/контекст, настроенное направление поиска и период.
3. Разделяет видео по длительности: менее 60 секунд, 60 секунд и более, длительность неизвестна.
4. Группирует по официальному `category_id`, полученному от YouTube API; не заменяет его собственной классификацией.
5. Сохраняет сырые поля и URL, ограничивая только число отображаемых элементов в Markdown/JSON-группе через `--limit`.
6. Сохраняет дату истечения исходного отчёта и предупреждения о сроке обновления/удаления API Data.

## Чего не делает

- Не определяет язык видео по названию или описанию.
- Не присваивает собственные темы/теги по тексту видео.
- Не объединяет семантически похожие видео.
- Не вычисляет скорость просмотров, трендовый балл, engagement ratio, sentiment или другие производные метрики.
- Не называет все видео короче 60 секунд YouTube Shorts.
- Не делает дополнительные запросы к YouTube API.

`RU` и `global` — контексты поисковых запросов из Stage 2, а не доказательство языка видео или местонахождения автора. `category_id` — категория YouTube, а не собственная тема проекта.

## Установка

Скопировать `src/video_farm/discovery_analysis.py` в соответствующий каталог проекта. В `src/video_farm/cli.py` добавить импорт, функцию-обёртку и parser-команду по инструкции `APPLY_PATCH.txt`.

## Запуск

```powershell
.\.venv\Scripts\python.exe -m video_farm.cli discover-analyze --input output\discovery\discovery.json --out output\discovery --limit 20
```

Результаты:

- `output\discovery\topics.json`
- `output\discovery\topics.md`

Команда работает только с локальным исходным отчётом, не требует API-ключа и не изменяет `discovery.json`.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m pytest tests\test_discovery_analysis.py -q
.\.venv\Scripts\python.exe -m video_farm.cli discover-analyze --help
```

## Следующая функциональность

Семантическая классификация, пользовательские поджанры/теги и тематические кластеры не включены. Официальная политика YouTube выделяет Content Categorization and Tagging как дополнительную производную аналитику, доступную только после явного принятия соответствующего дополнения и одобрения аналитического use case. До проверки одобрения для проекта эту функцию нельзя включать.


## Хранение и очистка

`topics.json` и `topics.md` повторяют часть исходных полей YouTube API и наследуют `source_refresh_or_delete_by_utc` из `discovery.json`. Команда `discover-cleanup` после наступления срока удаляет все четыре файла отчёта: `discovery.json`, `discovery.md`, `topics.json` и `topics.md`. Остальные файлы каталога не затрагиваются.
